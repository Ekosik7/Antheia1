# React frontend

Status: folder skeleton only. `src/` is reserved for future source; no components, package manifest or entrypoint exist.

Planned screens: Style DNA, My Closet, Add Item, AI Stylist, Recommendation Results, My Shop with Product / Price comparison, and optional Photo Analysis with Review Palette. Save/rate controls depend on the persistence scope.

The client will communicate with Go, not directly with PostgreSQL or Python. It must show editable filters, unknown availability, source timestamps, purchase subtotals and recoverable empty/error states.

[UX mockups/prototype location](../docs/ux/README.md): visual assets are pending. Setup and tests: not yet implemented.
