# Python image service

Status: folder skeleton only. `app/` and `tests/` contain placeholders; no models, preprocessing logic or dependency manifests exist.

Planned responsibilities: optional consented image preprocessing, quality checks, color / visual feature extraction, tentative palette suggestions and uncertainty or quality warnings. User corrections take precedence. The complete photo-free journey bypasses this service.

No exact body analysis, physical fit prediction or guaranteed seasonal color accuracy is promised. Model selection and the usefulness of season labels remain research decisions. Outfit ranking and prices belong to Go.
