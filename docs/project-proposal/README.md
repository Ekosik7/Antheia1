# Project proposal

Status: working draft derived from the current task and supplied documents; no separate approved proposal was supplied.

**Topic:** Development of an Intelligent Recommendation System for Personal Image and Style Personalization Based on Image Analysis and User Preferences.

**Problem:** outfit coordination, locating alternatives, spending information and photo privacy need consideration. Four interviews support preliminary needs, not population-wide prevalence or proven effectiveness.

**Goal:** design and later evaluate explainable recommendations combining Style DNA, a personal closet, a reproducible catalog and optional uncertain palette signals.

**Objectives:** specify requirements; design a React/Go/PostgreSQL/Python MVP; later implement filtering/scoring; compare preferences-only, compatibility and optional-photo variants; assess budget compliance, usability, privacy and response time.

**Deliverables:** research, requirements, architecture/diagrams, UX prototype, later implementation, reproducible evaluation and thesis/presentation.

**Open fields:** verified team, supervisor, schedule, permitted dataset, consent and evaluation sample. Combining features alone does not demonstrate novelty or superiority.
