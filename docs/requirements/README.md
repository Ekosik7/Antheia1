# Requirements baseline

The supplied `ANTHEIA_Requirements_Specification.docx` is preserved unchanged. Its stable FR-01–FR-34, NFR-01–NFR-18, business rules and acceptance scenarios remain the source baseline. Priorities describe proposed scope, not implementation status.

The current task adds explicit My Closet and Add Item concepts and selects React, Go, PostgreSQL, Python and Docker Compose. [Scope alignment](scope-alignment.md) records these additions without silently editing the baseline or inventing official FR identifiers.
