# UX flows and prototype placeholder

Status: textual flow plan only. No visual mockups, Figma link or interactive prototype was supplied or created. Future assets belong here.

| Current UX name | Planned interaction |
| --- | --- |
| Style DNA | Edit styles, liked/avoided colors, sizes and region without a portrait |
| My Closet | Browse, edit and remove owned garments |
| Add Item | Manual garment entry, optional item image, return to closet |
| AI Stylist | Set occasion/budget, review interpreted filters, request outfits |
| Recommendation Results | Inspect outfits, reasons and purchase subtotals |
| My Shop | Browse products, compare attributable offers, open retailer links |
| Optional Photo Analysis / Review Palette | Opt in, check quality, correct palette and delete photo |

Core journey: Style DNA → optional My Closet / Add Item → AI Stylist → results → My Shop or save/rate if enabled. Portrait analysis is a branch, never an onboarding gate. The future candidate policy should support closet-only outfits when sufficient compatible items exist and shopping-only requests with an empty closet.

Future states: empty closet, invalid item, no matching outfits, over-budget filters, unknown stock/price, unavailable catalog, declined consent, poor photo quality, image-service failure and deletion failure. Keep filters editable and distinguish owned garments from purchases. Shipping/tax unknown is not zero.

Prototype review must cover keyboard use, photo-free flow and mobile layout. Source widths 375/768/1440 px are proposed targets; no responsive screens exist yet.
